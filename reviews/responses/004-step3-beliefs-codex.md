# Codex review 004 — M0 step 3 beliefs

Reviewed `48c0832` on `main`, including the review 003 fixes. All 89 tests passed with Python 3.12.14 and NumPy 2.5.5. Two 600-second seed-2 CLI runs of `scenarios/test_beliefs.json` under different `PYTHONHASHSEED` values produced byte-identical JSON, with digest prefix `429fd2d02b352637`. The suite measured 290 ms per perception cycle for 200 entities and six commanders, equivalent to about 313 seconds of perception over a three-hour battle at the default cadence.

The normal perception phase reads enemy state to generate sightings after range and LOS filtering. The hidden reserve stayed absent under the suite's hidden-state interventions. I found two places to close before wiring decisions and report delivery: the belief API can accept or expose live mutable state, and the replay digest misses report-driven beliefs. The LOS probes also found a failure on static terrain and both types of invalid coarse result after a terrain edit.

## Findings

Run reproductions from the repository root. Below, `P = params.resolve()`, and `field = "scenarios/test_beliefs.json"`.

1. **High — Report and export APIs can bypass the belief boundary.** `imperatores/belief.py:34–58,97–115`. Both ingestion functions accept untyped contact values. The view freezes dictionaries and lists but returns arbitrary objects and tuples unchanged. The export function returns live contact and self dictionaries. **Reproduce:** Load the fixture and step once. Set `belief.to_json(w.beliefs[900])["contacts"][0]["x"] = w.entity(51).x`. A new view reads that value even though there was no corresponding sighting or report. For the forthcoming report path, take a valid report contact, set its `x` to `(w.entity(51),)`, merge it into officer 1's belief, and inspect that contact in `belief.view(w, 1)`. Its `x[0] is w.entity(51)` is true. Ordinary scalar sightings do yield detached views. These counterexamples require using the belief API and are absent from the current CLI flow. **Fix:** Validate types and finite values at ingress, store an owned immutable contact value, and produce a detached export. At delivery, accept a report payload captured from the sender's information at send time and link it to a delivery record. Add tests for mutation of export and input objects and for rejecting objects in scalar fields.

2. **High — Replay can certify identical runs with different decision inputs.** `imperatores/record.py:37–44,51–76`, `imperatores/systems/perception.py:85–117`, `imperatores/belief.py:45–60`. The rolling belief hash covers selected sighting arrays. It omits report merges, officer self knowledge, and contact fields such as facing, kind and receipt metadata. Periodic commander overlays cannot cover officer reports. The causal trace also omits mutable commander fields such as mobility and command assignments. **Reproduce:** Load two copies of the fixture with seed 1 and call `engine.step` on each. Only in copy B, merge `dict(id=51, side="B", kind="foot", x=2900., y=1500., pos_err=30., strength=300, order=None, facing=None, seen_t=0)` into officer 1's belief with `sender=900, received_t=1`. Run both for another 20 seconds. A's view has no contact 51 and B's view has the report, but `record.digest(a) == record.digest(b)` is true. **Fix:** Hash canonical belief mutations, including owned self updates and report receipts, or hash the actual decision-relevant state at defined boundaries. Trace mutable commander inputs when they can change. Test equal parameters and truth trajectories that differ only in an officer report and in a normally unsnapshotted field. The current test at `tests/test_beliefs.py:231–240` changes a parameter already hashed by the digest, so its second assertion cannot prove belief coverage.

3. **Medium — True world IDs identify contacts after an unseen break in tracking.** `imperatores/belief.py:12–16,34–42`, `imperatores/systems/perception.py:52,99–114`. The same ID is disclosed even in the unrecognised “troops” band and is matched on reacquisition without recognition evidence. The documented tracking assumption covers a body while it stays in sight. **Reproduce:** Load the fixture and run `perception.step(w)`. Commander 900 sees horse 52 at tick 0. Move it to (3000, 1500), set `w.tick=5` and run perception. Its contact remains at `seen_t=0`. Return it to (1500, 250), set tick to 10 and look again. The observer updates the old contact with `first_seen_t=0, seen_t=10`. Swapping two visually identical bodies while hidden would still associate each with its correct history. No contact is added during the unseen interval. **Fix:** Use observer-local track handles and reassociation based on observed attributes, or explicitly adopt perfect reacquisition as an additional assumption. Keep ground-truth links out of decision inputs.

4. **Medium — Both coarse LOS bounds can disagree with the exact pass after edits.** `imperatores/sight.py:34–61,72–94,172–186`, `imperatores/terrain.py:46–52`. Terrain arrays are mutable, while coarse bounds are cached without invalidation. **Reproduce:** On flat terrain of width 240, height 80 and cell size 20, query `line_of_sight(t,P,10,10,2,230,10,2)` to populate the cache. Set `t.ground[0,5]=terrain.WOODS`. The same query returns true. It returns false if `_quick` is patched to return two all-false masks, which forces the exact pass. For the converse, build width 400 with the same height and cell size, set `t.elev[:,4:16]=30`, and query from (10, 10) to (390, 10) at endpoint heights 2. The first result is blocked. Set `t.elev.fill(0)`. The cached result stays blocked while the exact pass is visible. **Fix:** Enforce immutable terrain after construction or version all terrain edits and rebuild the bound cache when the version changes. On a fixed map with finite values the padded elevation extrema and full-canopy upper bound are conservative under the same cell and interval conventions.

5. **Medium — Officer self knowledge is stale on movement ticks.** `imperatores/systems/perception.py:40–46,63–79`, `imperatores/engine.py:7–9`, `imperatores/belief.py:105–110`. The own snapshot is taken before movement on perception cycles only. The view exposes the current tick alongside earlier values without a self-observation timestamp. **Reproduce:** Give entity 1 a `move_to` task for (800, 1500) in the fixture, use `pace_jitter=0`, and step three ticks. At view tick 3 its own x is 700.0 while the entity has reached 705.8833. **Fix:** Refresh the narrowly defined own-state snapshot before decision evaluation, including non-perception ticks. If stale self knowledge is intentional, timestamp it and amend the documented assumption. The present self mapping contains the officer's own entity, and commander views contain no self location or rank. Define the allowed commander self context separately before decision code needs it.

6. **Medium — Beliefs reveal exact range through the uncertainty field.** `imperatores/systems/perception.py:91–98,104–114`, `imperatores/params.py:89`. `pos_err` stores the unrounded standard deviation computed from true distance, which can undo part of the position error by disclosing an exact radius around the observer. Close facing also copies the full-precision true angle. These fields follow a sighting. They are extra measurement assumptions, distinct from seeing an otherwise unseen body. **Reproduce:** After one fixture perception phase, calculate `w.beliefs[900].contacts[52]["pos_err"] * 1000 / P["pos_error_per_km"]`. The result, 1665.0825805346713 m, matches the true distance to floating-point precision. **Fix:** Derive confidence from perceived distance or publish a coarse confidence band. Document exact-facing perception or quantise it to the intended visual resolution.

7. **Medium — A legal partial edge cell breaks the claimed shared route cost.** `imperatores/pathing.py:59–74,114–134`, `imperatores/terrain.py:66–71`. The A* relaxation splits a centre edge into equal halves charged at its endpoint factors. With a clipped boundary cell a diagonal may cross two boundaries at different fractions and spend time in a third cell. The exact shortening cost then describes a different objective. **Reproduce:** Build width 41, height 60, cell 20, and `rough=[[20,40,40,60]]`. For formed foot, the edge from `t.centre(1,1)` to `t.centre(2,2)` goes from (30, 30) to (40.5, 50). Both endpoint cells are open. A* charges 22.5887 open-ground metres, while `segment_cost(t, pathing.factor_grid(t,P,"formed"), 30,30,40.5,50)` charges 29.4012. **Fix:** Use exact costs on clipped diagonals, keeping the fast half-edge formula where valid. Add a graph-cost oracle with partial cells.

8. **Medium — Load accepts positions on an impassable stream contact.** `imperatores/terrain.py:82–89,130–150`, `imperatores/scenario.py:98–104`, `imperatores/pathing.py:83–93,141–148`. Point passability assigns one cell, while movement treats every touching stream cell as blocked, including at the start and goal. **Reproduce:** Build width and height 100, cell 20, a width-1 stream from (50, 0) to (50, 100) and no fords. `t.passable(60,10)` is true, `t.segment_passable(60,10,70,10)` is false, and `pathing.plan(t,P,"formed",60,10,70,10)` returns `None`. A scenario can deploy an infantry unit there and then prohibit it from moving directly away from the bank. **Fix:** Use one contact rule for point validation and motion, or specify and implement how a legal bank contact may depart without entering the stream.

9. **Medium — Accepted scenario IDs can abort the first sighting.** `imperatores/scenario.py:25–29,61–65,80–82`, `imperatores/rng.py:25–31,80–84`. The scenario validates nonnegative IDs but RNG keys have an unsigned 32-bit limit. **Reproduce:** Change the fixture's first commander ID from 900 to `2**32`. Scenario load succeeds and the first `engine.step(w)` raises “keyed draw parts must be integers in [0, 2**32)”. **Fix:** Share ID and RNG key validation at load. Keep counter widths explicit for ticks and any later occurrence IDs.

10. **Low — The exact LOS pass drops positive-width canopy intersections near corners.** `imperatores/sight.py:91–93,97–107,118–136,149`. Intervals of fractional width at most `1e-12` are skipped even if a whole canopy height is present in that interval. **Reproduce:** Build width 240, height 80, cell 20, and `woods=[[100,40,120,60]]`. Query `sight.line_of_sight(t,P,11,48.9+1e-12,2,211,28.9+1e-12,2)`. The ray crosses a positive wood interval around x = 100 through x ≈ 100 + 1e-11. Both the normal and forced-exact query return true. Placing live opponents at those endpoints makes perception write the contact. This is a numerical boundary case. **Fix:** Define a physical grazing tolerance or handle positive intersections explicitly with robust crossing comparisons. Add an analytic corner case and state which side owns a ray on a wood edge.

11. **Low — Ford validation conflates crossing a stream with connecting separate map regions.** `imperatores/terrain.py:274–286`. A ford can cross between local banks even if both banks already connect around an end. **Reproduce:** On a 100 × 100 m field with 20 m cells, build a width-1 stream from (50, 25) to (50, 75) with `fords=[[50,50,1]]`. Loading rejects it as failing to join two banks even though the ford would open the entire stream width at y = 50. **Fix:** Test that the opening connects opposite local banks, or document that scenarios must model a field-separating barrier for a ford to be allowed.

## Pair independence, RNG and performance

I compared 5,000 static-map rays on a 5 m coordinate lattice with a forced exact-only pass, including grid and field edges. I also permuted the batch, forced small chunks, and reversed physical rays by swapping endpoints and their heights. All results agreed. Together with the existing unrelated-entity test, this supports pair independence for those cases. The scalar helper wraps the batch function, so comparing against it exercises batching rather than providing a geometric oracle. The 25 cm dense comparison in the review 003 regressions only asserts disagreements in the false-visible direction, and reuses the implementation's terrain and woods conventions. It cannot certify the exact or coarse paths separately.

The random draws are pure in seed, system, pair and cycle, and the output conversion uses 53 bits with a factor of 2⁻⁵³, so it cannot round to 1. A 64-bit mixed state cannot encode three arbitrary 32-bit key components injectively. This is a collision risk under the current construction, with no concrete collision found in the exercised keys. Document the expected collision risk and domain-separate key schemas and draw counters. If uniqueness is required, use a wider counter-based generator with an injective key encoding. Box–Muller avoids log(0) by replacing zero with `1e-300`, which would give a radial value of about 37.17 on the rare all-zero uniform. A mapping to a strictly open uniform interval can avoid introducing that tail artifact. The current distribution test checks means and standard deviations over a small sample.

The registries label the new perception numbers as engineering assumptions with ranges. Friend/foe copies the seen side and recognition bands behave as tested. A fit-zero body is removed from the sighting candidates immediately, so a visible destroyed formation leaves only its stale prior contact. Define that observation policy when combat lands. Perception also ignores officers' heading for attention. Its “sector” is currently a radius.

The exact pass sorts similar-sized lines, but the coarse pass allocates a rectangular batch before chunking. The `_CHUNK_POINTS` estimate also uses the summed span per pair, while actual columns use separate batch maxima for x and y. Cap both passes by their actual padded dimensions. For repeated perception cycles on static terrain, cache geometric LOS for unchanged endpoint positions and heights, with the terrain revision and sight settings in the key. Apply range filtering and draw errors per pair and cycle as before. Reverse-ray reuse is safe only with matching physical endpoint heights, which ordinary eye/target swaps need not have.

## Scope limits

I read the approved specification, review 003 response, step 3 notes, scoped code and tests. The existing regressions pass for the original stream-edge gap, ford stalls, canopy clips, low crests, injected routes and winding-grid shortening effort. I did not run CI, Python 3.10 or 3.13, other platforms, a full 200-entity battle, exhaustive geometry or RNG collision searches. I did not assess formation footprints, historical calibration, or the step 4 and 5 messenger and decision systems. This review does not establish the information-integrity gate for decision records.
