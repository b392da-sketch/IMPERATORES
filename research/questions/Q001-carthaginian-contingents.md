# Q001 — Contingent types for a Carthaginian-style army, Second Punic War

**Status:** open, not yet sent (22 November 2026)
**Needed for:** M0 default scenario (the Carthaginian-style order of battle)

**Decision it informs:** which unit types the M0 scenario uses for the Carthaginian side, and the formation, equipment class and rough size each starts with.

**Already in Notion:** Carthaginian institutions and multi-contingent organisation (Phases X, XXX), Hannibal's Iberian contingents released home (Polybius 3.33, Phase XXXI), the three echelons at Zama (Polybius 15.16), Cannae's African infantry and cavalry (Polybius 3.113–116).

**What is needed:** for each contingent type commonly reported in Hannibal's or Hasdrubal's field armies, 218–202 BCE (for example Libyan/African heavy infantry, Iberian and Celtic infantry, Balearic slingers, Numidian light horse, Iberian and Celtic heavy horse):

1. typical arms and protection, as reported, with any change over the war (for example Libyans re-equipped with Roman arms after Trasimene, if the sources support it);
2. how they formed up and fought, as far as the sources say, including how deep or open the formation was;
3. contingent sizes as ancient authors report them for named battles, labelled as author-reported figures;
4. where the sources or modern scholars disagree.

**What ends the inquiry:** a table of 5–8 unit types with those four columns and source grades. Contingents that cannot be characterised beyond their name are listed as such; no further digging into them for M0.
