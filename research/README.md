# Research questions

Questions for historical research (ChatGPT), raised when a build step needs them. Answers feed the simulation's provisional values and options; the full archive stays in Notion (IMPERATORES Research Hub).

## Rules

- **Every question names the decision it informs.** If no design choice could change with the answer, it isn't asked.
- **Every question says what ends it.** Research stops when that condition is met, even if the scholarship goes on.
- **Check Notion first.** Say what the Research Hub already covers, so the question asks only for what is missing.
- **Ranges and alternatives, not single truths.** Where the evidence is contested, the useful answer is the set of reconstructions the model must be able to represent, with source grades.
- **Mark what was read.** Ancient passages and modern works as read in full, in part, or known only from summary or abstract.

## Format

One file per question in `questions/`, named `QNNN-short-name.md`:

- **Status:** open / sent / answered / closed (with date)
- **Needed for:** the build step or milestone
- **Decision it informs**
- **Already in Notion**
- **What is needed**
- **What ends the inquiry**
- **Answer:** saved as `QNNN-short-name-answer.md` next to the question, unchanged; Claude's notes on how it was used follow in the question file.
